# Глоссарий и правила перевода Paperclip → русский

Этот документ — единственный источник правды по терминам. Любой новый перевод
(в том числе после обновления Paperclip) обязан ему следовать.

## 1. Что такое Paperclip

Paperclip — самостоятельно размещаемая система управления командой ИИ-агентов:
оргструктура, задачи, бюджеты, согласования, регламенты и аудит. Интерфейс
выглядит как таск-трекер, но управляет «компанией из агентов».

## 2. Стиль

| Правило | Пояснение |
| --- | --- |
| Обращение | На «вы» со строчной буквы, без «Вы». |
| Кнопки и действия | Инфинитив: «Сохранить», «Отменить», «Создать задачу». |
| Заголовки разделов, вкладки, пункты меню | Существительное в им. падеже: «Задачи», «Затраты». |
| Подписи-описания под заголовком | Полное предложение с точкой, если в оригинале есть точка. |
| Тон | Деловой, короткий, без канцелярита и без фамильярности. |
| Буква «ё» | Пишем: «её», «учётная», «тёмная». |
| Кавычки | «Ёлочки» внутри текста; вложенные — „лапки“. |
| Тире | Длинное тире «—» с пробелами; дефис не заменяем. |
| Числа | Неразрывный пробел не используем, формат чисел не меняем. |

## 3. Технические правила (обязательные)

1. **Пробелы по краям строки сохраняются ровно как в оригинале.** Строка
   `"Issue "` переводится как `"Задача "` — с тем же хвостовым пробелом.
2. **Финальная пунктуация сохраняется.** Есть точка — есть точка; нет — нет.
   `…` и `...` переносятся в том же виде.
3. **Плейсхолдеры не трогаем**: `{{name}}`, `{0}`, `%s`, `$1`, `:id`, `<b>`,
   markdown-разметка, символы `•`, `·`, `→`.
4. **Заглавные буквы в стиле Title Case** приводим к нормальному русскому
   регистру: `New Task` → «Новая задача», а не «Новая Задача».
5. **Не переводим** названия продуктов, компаний, протоколов, форматов, команд,
   моделей и путей: Paperclip, OpenClaw, Claude, Claude Code, Codex, Cursor,
   Gemini, Grok, Hermes, GitHub, GitLab, Slack, Discord, Vercel, Docker, Postgres,
   Node.js, npm, pnpm, git, SSH, MCP, API, REST, JSON, YAML, TOML, CSV, HTML,
   Markdown, cron, URL, UUID, ID, JWT, OAuth, SSO, RBAC, GRC, LLM, CLI, UI, SDK,
   E2B, Daytona, Modal, Novita, Kubernetes, Tailscale, OpenTelemetry, webhook
   (как часть названия), а также имена шрифтов, клавиш (`Esc`, `Ctrl`, `Shift`,
   `Enter`, `Tab`) и идентификаторы вроде `AGENTS.md`.
6. Если строка целиком непереводима (бренд, код, идентификатор, единица
   измерения) — она просто не попадает в словарь.
