# Каталог `docs`

Постоянная документация проекта. В каталоге не хранятся отчёты отдельных
проверок, временные спецификации, handoff-файлы и выгрузки разговоров.

| Файл или каталог | Назначение |
| --- | --- |
| `ARCHITECTURE.md` | Компоненты CLI, границы runtime/development и модель безопасного изменения bundle. |
| `COMPATIBILITY.md` | Проверенные версии Paperclip и уровень поддержки каждой версии. |
| `GLOSSARY.md` | Канонические переводы терминов интерфейса. |
| `RELEASING.md` | Порядок сборки, проверки и публикации GitHub Release. |
| `TESTING.md` | Уровни тестирования и команды локального/официального контура. |
| `TRANSLATION-GUIDE.md` | Слои словаря, происхождение строк и рабочий процесс перевода. |
| `TROUBLESHOOTING.md` | Диагностика установки, конфликтов и восстановления. |
| `images/` | Проверенные снимки локального демонстрационного стенда для README. |

Операционный runbook агента находится только в корневом
[`../AGENTS.md`](../AGENTS.md).
