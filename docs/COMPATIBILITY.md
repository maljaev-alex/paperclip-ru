Текущая стабильная версия — **2026.1106.0**. Для неё и для 2026.1023.0 нужен
русификатор **v1.0.5** или новее. Эти два выпуска входят в 30-дневное окно
с 19 октября по 18 ноября 2026 года. Сборки 2026.1012.0 и 2026.1005.0
поддерживаются с v1.0.4.

Для 2026.1106.0 зарегистрированы npm integrity и точные отпечатки 385 файлов
JS/HTML из `ui-dist`, для 2026.1023.0 — 267 файлов. Обязательные проверки включают
`doctor`, dry-run, `apply`, `verify`, повторный `apply`, браузерные маршруты
в обоих режимах и byte-identical `revert`.
Для 2026.1001.0 сохранены
[результаты проверки официального UI](https://github.com/maljaev-alex/paperclip-ru/actions/runs/37325325455).
Для более ранних сборок сохранены даты и
[результаты прежней проверки](https://github.com/maljaev-alex/paperclip-ru/actions/runs/36498680277).
Перед созданием GitHub Release workflow проверяет окончательные архивы
на каждой версии из текущего окна с изменением ширины панелей и без него.

Страницы подключения ассистента начиная с 2026.1012.0 требуют настроенного
authenticated-режима и пользовательской сессии. Их браузерная проверка
выполняется на отдельном authenticated/private сервере с фиктивным
владельцем. В `local_trusted` upstream не монтирует `/api/mcp/setup` и
`/api/mcp/connections`; русификатор не добавляет эти серверные API.

В официальном Layout страница `/apps/byo` ошибочно классифицируется как ID
подключения и вызывает лишний запрос с 404. Точное исправление frontend-таблиц
маршрутов в v1.0.4 устраняет этот запрос. На исходных сборках 1005/1012 ошибка
воспроизведена без перевода; после apply форма BYO отображается без ошибок,
а revert побайтово возвращает исходный интерфейс. Все прочие HTTP-ошибки
по-прежнему блокируют приёмку.

В 2026.1106.0 Paperclip загружает прежний вариант боковой панели отдельным
JS-файлом. Русификатор сверяет импорт и оба обработчика маршрутов перед
исправлением BYO. Для обеих новых сборок исправлен переход из вложенного
файла навыка на вкладку «Обзор».

Октябрьский выпуск добавляет переводы вебхуков регламентов, ботов проверки
GitHub, подключения Slack и новых MCP-сервисов. Названия провайдеров,
скопированные инструкции агентов и описание встроенного навыка `first-task`
сохраняются как исходные данные. Короткие неоднозначные подписи исключены из
статической замены; их перевод выполняется с защитой пользовательского контекста.

Сентябрьский интерфейс дополнительно проверяет чаты агентов, подключение
каналов, разрешения, API-ключи и редакции инструкций. Фиктивный чат создаётся
без отправки сообщений и запуска агента; у связанной задачи есть план.
Редактор сравнивается с исходным UI той же версии, а пользовательские названия,
инструкции и Markdown сохраняются без перевода.

`full` означает чистую обязательную матрицу на официальной сборке. У
`2026.817.0` уровень `best-effort`, потому что её исходный frontend обращается к
отсутствующему в том же official package endpoint
`/api/companies/:id/built-in-agents` и получает 404. Ошибка воспроизводится без
русского overlay; все проверки перевода, panel-resize и точного отката прошли.
Фикстура `2026.831.1-synthetic` используется только в автономных тестах и не
считается официальной сборкой.

Windows и Linux: Node 20+ для paperclip-ru. Для запуска самого Paperclip
2026.831.x, 2026.916.x, октябрьских и ноябрьских stable нужен Node 24.11+. macOS остаётся experimental: обязательная локальная
приёмка выполняется на Windows/Linux, а дополнительная CI-задача macOS допускает
ошибку и не считается подтверждением поддержки.

Несовпадение файлов с официальным отпечатком блокирует первый apply даже при
известном номере версии. `--force-baseline` — отдельное ручное исключение.
Обновление Paperclip требует `reapply`; обновление русификатора — `update`.
Новая версия инструмента может добавить поддержку сборки, которую старая версия
отклоняла. Перед заменой инструмента новый CLI доказывает совместимость.

Еженедельный workflow заново получает все stable-релизы за последние 30 дней и
проверяет каждый на отдельном сервере с тестовой базой в обоих режимах. Только
повторно подтверждённая ошибка создаёт issue. Workflow не меняет список
поддерживаемых версий и не принимает неизвестный fingerprint автоматически.
