# Каталог `docs/images`

Снимки локального демонстрационного стенда Paperclip в тёмной теме. Кадры
показывают реальную работу русского overlay без адресной строки браузера,
паролей, токенов и системных окон.

| Файл | Назначение |
| --- | --- |
| `dashboard.jpg` | Обзор: агенты, показатели и активность. |
| `issues.jpg` | Иерархический список задач и статусы. |
| `agents.jpg` | Список агентов, модели и состояния. |
| `projects.jpg` | Портфель проектов. |
| `costs.jpg` | Затраты, бюджет и финансовая аналитика. |
| `activity.jpg` | Журнал действий организации. |
| `skills.jpg` | Каталог установленных навыков. |

Перед обновлением проверяйте, что JPEG не содержит EXIF/текстовых метаданных,
секретов, уведомлений ОС или данных вне разрешённого демонстрационного стенда.
