# Troubleshooting

| Симптом | Проверка и действие |
| --- | --- |
| Paperclip не найден (3) | `doctor --json`; указать `--server-dir` пакета `@paperclipai/server` |
| Неизвестная сборка (4) | Обновить русификатор; проверить `docs/COMPATIBILITY.md` |
| Конфликт хешей (5) | Сохранить baseline/journal, прочитать `verification`/`details`; автоматическую запись не продолжать |
| Нет прав (6) | Проверить `doctor`; выбрать доступный пользовательский каталог |
| Подозрение на незавершённую запись | `doctor`, `status`, `verify` не меняют диск; следующая mutation восстанавливает только доказанный snapshot |
| Recovery заблокирован | Устранить указанную стороннюю модификацию или повреждение доказательств вручную; не удалять baseline/journal первым действием |
| Ложное предупреждение в Instructions | Проверить версию оверлея и `risks` dry-run; неизвестная сигнатура оставляет штатный dirty guard |
| Английский placeholder | Проверить `verify`, затем hard reload; содержимое поля не переводится |
| Панель не меняет ширину | Модуль включается только `--with-panel-resize` |
| Нет опубликованного Release | Использовать проверенный локальный архив через `--source-dir` |

`window.confirm` остаётся штатным. Нормализация используется только в сравнении
начальной сериализации MDXEditor до пользовательского ввода, не в сохраняемом
тексте. После ввода сравнение точное.

Lifecycle update хранит полный snapshot инструмента и ui-dist до активации новой
версии. `details.rollbackOk=true` означает восстановление исходных деревьев и
проверку предыдущим CLI. При `false` доказательства сохраняются, следующие записи
блокируются. Не делайте дополнительный revert поверх успешно восстановленного
состояния. Предупреждение об очистке после commit означает, что операция уже
проверена; следующая lifecycle-команда завершит только удаление recovery-метаданных.

Диагностика браузера: `__paperclipRu.diagnostics`, `__paperclipRu.missing()`.
Вторая команда показывает и допустимый английский контент, поэтому её результат
нуждается в проверке контекста и не равен списку ошибок перевода.
