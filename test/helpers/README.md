# Каталог `test/helpers`

Общие тестовые утилиты, не входящие в runtime CLI.

| Файл | Назначение |
| --- | --- |
| `copy-fixture.mjs` | Создание, инвентаризация и безопасная очистка временных fixture-каталогов. |
| `official-seed.mjs` | Заполнение одноразовой БД официального Paperclip тестовыми сущностями. |
| `release-variant.mjs` | Построение контролируемых вариантов релиза для update/rollback-тестов. |
| `route-allowlist.mjs` | Разрешённые бренды, технические строки и исключения маршрутной матрицы. |
