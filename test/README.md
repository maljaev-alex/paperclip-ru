# Каталог `test`

Автоматические проверки проекта. Тесты используют только изолированные
fixture-каталоги или явно заданные одноразовые официальные серверы Paperclip.

| Каталог | Назначение |
| --- | --- |
| `unit/` | Быстрые проверки отдельных модулей и контрактов данных. |
| `integration/` | Полный lifecycle, архивы, журнал транзакций и bootstrap-скрипты. |
| `e2e/` | Браузерные проверки синтетического frontend fixture. |
| `official/` | Браузерные проверки настоящего npm-релиза Paperclip. |
| `fixtures/` | Минимальные входные данные для автономных тестов. |
| `helpers/` | Общие функции подготовки и очистки тестовых стендов. |

Основные команды перечислены в [`../docs/TESTING.md`](../docs/TESTING.md).
Нельзя направлять destructive/fault-injection тесты на рабочую установку.
