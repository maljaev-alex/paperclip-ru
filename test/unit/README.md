# Каталог `test/unit`

Быстрые тесты чистых функций и неизменяемых контрактов.

| Файл | Проверяет |
| --- | --- |
| `archive-svg.test.mjs` | Безопасное чтение ZIP/TAR и строгий SVG/XML. |
| `cli-paths.test.mjs` | Аргументы CLI, приоритет путей и schema manifest. |
| `coverage-siblings.test.mjs` | Классификацию непереведённых sibling-групп. |
| `dictionary.test.mjs` | Приоритет словарей, scopes, plural и динамические ключи. |
| `fixture-fingerprint.test.mjs` | Стабильность синтетического fingerprint. |
| `fs-atomic.test.mjs` | Атомарную замену, mode и Windows sharing retry. |
| `overlay-lint.test.mjs` | Состав overlay и read-only lint. |
| `recent-stables.test.mjs` | Расчёт 30-дневного окна stable-релизов. |
| `repository-layout.test.mjs` | README в каждом versioned-каталоге и отсутствие старых отчётов. |
| `strings.test.mjs` | AST-границы переводимых строк и защиту ключей/кода. |
