# Каталог `data`

Машиночитаемые данные, по которым CLI определяет совместимость, проверяет
официальный frontend и собирает релиз. Файлы этого каталога входят в исходный
архив для пользователей и участников разработки.

| Файл | Назначение |
| --- | --- |
| `compatibility.json` | Поддерживаемые версии Paperclip, 30-дневная политика и результаты проверок. |
| `fingerprints.json` | SHA-256 и состав официальных `ui-dist`, разрешённых для безопасного патча. |
| `lint-warning-baseline.json` | Проверенная база известных предупреждений словаря; новые предупреждения не должны маскироваться ею автоматически. |
| `release-config.json` | Репозиторий, канал, минимальные версии Node/PowerShell и параметры GitHub Release. |

При добавлении совместимости сначала проверяйте официальный npm-пакет, затем
обновляйте `compatibility.json` и `fingerprints.json` вместе. Процедура описана
в [`../docs/COMPATIBILITY.md`](../docs/COMPATIBILITY.md).
