# Каталог `locales`

Версионируемые слои русской локализации. Итоговый exact-словарь загружается в
порядке `ru.bulk.json` → `ru.catalog.json` → `ru.manual.json` → `ru.json`, после
чего применяются исключения и контекстные правила.

| Файл | Назначение |
| --- | --- |
| `ru.bulk.json` | Большой детерминированно отсортированный словарь, собранный из проверенных переводов. |
| `ru.catalog.json` | Курируемый каталог общеупотребительных UI-строк. |
| `ru.manual.json` | Небольшой ручной слой исправлений до локальных overrides. |
| `ru.json` | Приоритетные ручные overrides; обычное место для точечных правок формулировок. |
| `ru.rules.json` | Контекстные регулярные правила и шаблонные фразы. |
| `ru.plurals.json` | Русские формы числительных и счётчиков. |
| `no-exact.json` | Ключи, запрещённые для безусловной exact-замены. |
| `no-static.json` | Строки, которые нельзя патчить статически в bundle. |
| `coverage-exceptions.json` | Обоснованные исключения из оценки покрытия. |
| `latin-allowlist.json` | Допустимые латинские термины, бренды и технические обозначения. |
| `operator-required.json` | Строки операторского UI, обязательные для покрытия. |

`locales/parts/` создаётся только как временная рабочая область и не хранится в
Git. Инструкции для изменений: [`../docs/TRANSLATION-GUIDE.md`](../docs/TRANSLATION-GUIDE.md).
